Dataset Drift Preflight

An IntelliJ IDEA plugin for comparing a previous known-good CSV file with an updated version. Version 0.3.0-beta is available for free on JetBrains Marketplace.

Schema differences Detect added and removed columns and numeric-to-text changes.
Data-quality alerts Flag large row-count decreases, missing values, duplicate or empty keys.
Local by design Files are selected by the user and checked locally. No product account or cloud data upload is required.

How it works: Tools → Compare CSV Datasets… → select baseline and current CSV → optionally enter a key → review PASS, WARN or FAIL.

Limits: UTF-8 CSV only; 5 MB and 50,000 rows per file in this prototype. No XLSX or Parquet. Results are heuristic, not a guarantee that data is safe to import.
