Support and documentation

How to use

  1. In IntelliJ IDEA, open Tools → Compare CSV Datasets…
  2. Select a baseline UTF-8 CSV and a current UTF-8 CSV.
  3. Optionally enter an identifier column such as product_id.
  4. Read the PASS, WARN, or FAIL report. Review all findings before importing data elsewhere.

Supported inputs

UTF-8 CSV files up to 5 MB and 50,000 data rows per file. No Excel/XLSX or Parquet input in v0.3.0-beta.

Troubleshooting

If the plugin reports an error, verify file encoding, file size, delimiter, and identifier-column spelling. The analysis is heuristic; a PASS result does not establish data correctness.
